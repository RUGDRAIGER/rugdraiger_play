RUGDRAIGER PLAY — Instalación en macOS
========================================

1. Descarga RugdraigerPlay-macOS.zip desde la página de GitHub.

2. Descomprime el ZIP (doble clic).

3. Arrastra "Rugdraiger Play.app" a la carpeta Aplicaciones (opcional).

4. Primera apertura (app con firma local, no notarizada por Apple):

   Si macOS dice: "Rugdraiger Play.app está dañado y no se puede abrir"
   → NO lo tires a la Papelera. La app NO está rota; macOS bloquea descargas
     de internet sin certificado de desarrollador (Gatekeeper).

   Solución A — Terminal (recomendada):
     Abre Terminal y ejecuta (ajusta la ruta si la app está en otra carpeta):

     xattr -cr "/Applications/Rugdraiger Play.app"

     Si aún no la moviste a Aplicaciones:
     xattr -cr ~/Downloads/RugdraigerPlay-macOS/Rugdraiger\ Play.app

     Luego abre la app con doble clic.

   Solución B — Clic derecho:
     Clic derecho en "Rugdraiger Play.app" → Abrir → Confirmar "Abrir"

   Solución C — Ajustes del Sistema:
     Ajustes del Sistema → Privacidad y seguridad → "Abrir de todas formas"

5. Escaneo automático de música:

   Al pulsar "Escanear dispositivo", macOS puede pedir autorización para las
   carpetas protegidas. La app revisa las ubicaciones estándar disponibles:

     • Escritorio
     • Documentos
     • Descargas
     • Música

   También puedes usar "Elegir carpeta…" para añadir otra ubicación.

   Si faltan archivos: Ajustes → Privacidad y seguridad → Acceso total al disco
   → activar Rugdraiger Play.

Requisitos: macOS 13 (Ventura) o superior y Apple Silicon (M1, M2, M3 o M4).

Compilar desde el código:
  cd macos && chmod +x build-macos.sh && ./build-macos.sh

Nota para distribución pública:
  La firma local sirve para probar en el Mac que compila la app. Para evitar
  avisos de Gatekeeper en otros Macs se requiere un certificado Developer ID y
  notarización de Apple.
